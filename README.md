Renamed Disco-Babble partway through development.

Made as part of Global Game Jam 2026.

This is the webapp of a game requiring physical blocks to play.\n
Here is a link to images of the game blocks if you want to create them: https://docs.google.com/document/d/1CgRstffE-NHIy7jOYpcbIXeoaxsQvvc7GdYs0C1ROoU/edit?usp=sharing \n
The webapp allows players to hear secret messages based on their role and the current round of the game.

This webapp is made with React and hosted on Vercel.\n
Here is the address: https://disco-babble.vercel.app/\n
Here is the game's itch address: https://lazalien.itch.io/discobabble\n

Initially, it had a Supabase database that allowed more nuanced coordination of games.\n
But this was unnecessary and removed.\n
That version of the game is preserved in the branch `many-games` in case those ambitions return.
